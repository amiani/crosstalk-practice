# Generation bounded by a stable session profile

Practice sentences are written from a session profile derived once from the whole transcript, staying mostly within its vocabulary and constructions; responses shift emphasis and difficulty but never change the profile. Repeats are prevented by showing the writer only recent sentences and struggles, and by rejecting exact duplicates (ignoring case, punctuation and spacing) against every sentence the practice session has had, accepting that near-duplicates can slip through.

## Considered Options

- **Anchor each sentence to a specific heard utterance**: rejected by the learner as too tight.
- **Send every previous sentence to the writer**: rejected because the prompt grows without bound and still wouldn't guarantee novelty.
