# Binary, trusted responses and no spaced repetition

The goal is understanding unheard sentences built from familiar material, not memorisation, so a responded-to sentence is never deliberately replayed and there is no spaced-repetition or mastery model. A response is only understood or didn't understand, trusted even when the translation was revealed first; struggles among the last ten responses steer the next few generations toward simpler variations and then fade out. A single binary signal is too coarse to justify flashcard-style scheduling, so its absence is deliberate.
