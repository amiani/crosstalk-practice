# One practice session at a time

The tool holds at most one practice session, and preparing a new recording means starting over, which deletes the previous one entirely. We chose this over a library of recordings or mixing sessions into one practice stream because the prototype only needs to show that practice grounded in the latest crosstalk session helps, and mixing raises open questions of weighting and staleness. The database enforces the single session, so supporting several later is a schema and product change, not a toggle.
